# Handled LA — Concierge Services Website

A responsive marketing website for Handled LA, a concierge and lifestyle-support service. The experience introduces services, explains how support works, compares monthly plans, and directs prospective customers to start a conversation.

## Product problem

Prospective customers need to understand what a concierge service can take off their plate, how engagement works, and how to get started without navigating a complicated intake process.

## Product experience

- **Clear service discovery:** appointments and scheduling, errands, groceries, travel coordination, household planning, and administrative tasks.
- **Simple conversion path:** prominent text and introductory-call actions.
- **Transparent package comparison:** three monthly support tiers with service details.
- **Responsive design:** layouts for desktop and mobile.
- **Visual explanation:** example messaging conversation, service steps, and motion-based transitions.

## Implementation

The public repository contains a React 19 / Vite landing page using Tailwind CSS, Framer Motion, and Lucide icons.

```bash
npm install
npm run dev
npm run build
npm run lint
```

The build and lint commands are available in `package.json`. A successful current build, public deployment, conversion improvement, or production customer volume has **not** been independently verified for this portfolio description.

## Portfolio notes

This is a website and customer-acquisition experience, not a full concierge operations platform. Product decisions emphasize fast comprehension, straightforward pricing, and low-friction contact over feature volume.
